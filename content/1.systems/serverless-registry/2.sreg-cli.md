`sreg` is the only way to publish a version to [Serverless Registry](/systems/serverless-registry). It packages the project,
uploads the files straight to R2 through presigned URLs and commits the version through the registry's API. Published
versions are immutable. It also downloads generic files and writes credentials for package managers, including GitHub Actions OIDC tokens.
Administration (credentials, yank, delete) is done in the registry's web panel.

## Setup

Release binaries are published for macOS (arm64, x86_64), Linux (x86_64 glibc and musl, arm64) and Windows (x86_64).

::code-group
```bash [macOS / Linux]
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/kduma-OSS/serverless-registry-cli/releases/latest/download/sreg-cli-installer.sh | sh
```
```powershell [Windows]
powershell -ExecutionPolicy Bypass -c "irm https://github.com/kduma-OSS/serverless-registry-cli/releases/latest/download/sreg-cli-installer.ps1 | iex"
```
```bash [Cargo]
cargo install --git https://github.com/kduma-OSS/serverless-registry-cli --locked sreg-cli
```
::

In GitHub Actions use the [actions](/systems/serverless-registry/github-actions) instead - they install `sreg` with checksum verification.

## Configuration

There is no configuration file, only flags and environment variables:

| Flag | Environment variable | Description |
| --- | --- | --- |
| `--registry <url>` | `REGISTRY_URL` | Base URL of the registry, e.g. `https://packages.example.com`. |
| `--token <token>` | `REGISTRY_TOKEN` | Token in the form `<project>:<secret>`. |

The token can also be part of the registry URL (`https://<login>:<password>@packages.example.com`, `https` only, percent-encode special characters).
Treat such a URL as a secret. Other global options: `--json` and `-v`/`--verbose`.

## Commands

| Command | What it does |
| --- | --- |
| `sreg composer publish` | Archives the package (`git archive`) and reads `composer.json`. |
| `sreg npm publish` | Runs `npm pack`; scoped packages only; `--tag` sets the dist-tag, `--workspace` selects a workspace. |
| `sreg cargo publish` | Runs `cargo package`; `--package` selects a crate. |
| `sreg nuget publish` | Runs `dotnet pack`; uploads `.nupkg` and `.snupkg`. |
| `sreg swift publish --scope <scope>` | Runs `swift package archive-source`. |
| `sreg maven publish --from-dir <dir>` | Publishes from a local Maven repository the build deployed to (Maven or Gradle). |
| `sreg generic publish <name> <version> <file>...` | Publishes arbitrary files with labels and metadata. |
| `sreg generic get <name> [version]` | Downloads files, verifying size and SHA-256. |
| `sreg auth <ecosystem>` | Writes credentials (`auth.json`, `.npmrc`, `credentials.toml`, `nuget.config`, `.netrc`, `settings.xml`); `--oidc` uses GitHub Actions OIDC. |
| `sreg whoami` | Shows the identity and grants of the current token. |
| `sreg version` | Prints the version of `sreg` and, with `--registry`, the registry's. |

All publish commands accept `--dry-run`, `--skip-existing` (exit `0` instead of `2` when the version exists) and `--oidc`.
`sreg` never runs the native tools' `publish`; only their packing commands. Extra flags for them go after `--`.

## Usage

::code-group
```bash [Composer]
git tag v1.2.3
sreg composer publish
```
```bash [npm]
sreg npm publish --tag next -- --ignore-scripts
```
```bash [cargo]
sreg cargo publish --package acme-core --tag-prefix core/v -- --locked
```
```bash [NuGet]
sreg nuget publish --version 1.2.0 -- -c Release
```
```bash [Generic]
sreg generic publish tools/acme-tool 1.0.0 dist/acme-linux.tar.gz --label os=linux
sreg generic get tools/acme-tool '^1.0' --label os=linux --sole --out acme.tar.gz
```
::

The version comes from `--version` or from the release tag on `HEAD` (`v1.2.3`; `--tag-prefix` for monorepos, e.g. `sdk/v1.2.3`).
For all ecosystems, monorepo options and packaging details see the
[README](https://github.com/kduma-OSS/serverless-registry-cli#readme){:target="_blank"}.

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Success. |
| `1` | Generic error. |
| `2` | The version already exists (`409`). |
| `3` | `sreg` is too old for the registry (`426`) - update it. |
